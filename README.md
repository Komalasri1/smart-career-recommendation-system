🚀 Smart Career Recommendation System

An AI-powered Smart Career Recommendation System that analyzes user skills, interests, and resumes to recommend suitable career paths intelligently.

---
Features:

- 🎯 AI-based Career Recommendation
- 📄 Resume PDF Upload & Analysis
- 📊 Skill Match Visualization
- 🧠 Intelligent Career Suggestions
- 💡 Suggested Skill Improvements
- 🌐 Full Stack Deployment
- 📱 Responsive Modern UI

---

 Technologies Used:

 Backend
- Java
- Spring Boot
- Maven
- REST API
- PDFBox

Frontend
- HTML
- CSS
- JavaScript
- Chart.js

Deployment
- Render (Backend)
- Vercel (Frontend)
- GitHub
